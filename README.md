# SCT Engineering Works portfolio

Bilingual professional portfolio for SCT, focused on mechanical design, precision metrology, special-purpose machines, robotic vision, and technical project delivery.

## Local development

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run check
npm run build
```

## Deployment

The site deploys to GitHub Pages through `.github/workflows/deploy.yml`. In the repository settings, select **GitHub Actions** as the Pages source.

## Public disclosure boundary

This repository contains only generalized, non-confidential descriptions and independently created presentation material. Employer-owned CAD, drawings, code, data, dimensions, photographs, and internal documentation are excluded.

All portfolio text and visual identity are reserved. Source code may not be reused without permission.
